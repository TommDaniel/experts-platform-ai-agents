# Design

## Diretrizes

- Interface **clean, minimalista e elegante**.
- Paleta em **tons pastéis**.
- **Somente tema claro** (light theme) — não usar dark mode.
- UI **acessível** e **responsiva** (ver `DEVELOPMENT.md`).

## Paleta

Tokens de cores (variáveis CSS):

| Token            | Valor     |
| ---------------- | --------- |
| `--powder-petal` | `#eddcd2` |
| `--linen`        | `#fff1e6` |
| `--soft-blush`   | `#fde2e4` |
| `--petal-frost`  | `#fad2e1` |
| `--light-cyan`   | `#c5dedd` |
| `--mint-cream`   | `#dbe7e4` |
| `--parchment`    | `#f0efeb` |
| `--alice-blue`   | `#d6e2e9` |
| `--pale-sky`     | `#bcd4e6` |
| `--powder-blue`  | `#99c1de` |

## Uso previsto

- **Fundos e superfícies**: `--linen`, `--parchment`, `--mint-cream`
- **Destaques e interação**: `--powder-blue`, `--pale-sky`, `--alice-blue`
- **Estados e sinalização**: `--light-cyan` (sucesso/info), `--soft-blush` e `--petal-frost` (aviso/erro)
- **Contraste sobre fundo claro**: `--powder-petal`
