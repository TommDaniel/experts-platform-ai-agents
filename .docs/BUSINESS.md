# Negócio

## Visão

Plataforma de **gestão de agentes de IA customizados** que atuam como especialistas em áreas/posições específicas de uma empresa.

## Conceito

Cada "expert" é um agente configurado para visualizar, analisar e trabalhar como um profissional sênior de uma área:

- **CEO expert** — visão e análise de negócio da empresa.
- **CMO expert** — visão e análise de marketing da empresa.
- **CTO expert** — visão e análise de tecnologia da empresa.

## Fontes de dados

Os experts baseiam seus trabalhos em dados puxados de conectores externos. Exemplos de conectores previstos:

- Notion
- Google Drive
- Google Docs
- Google Sheets
- PDF
- Markdown
- Confluence
- Jira
- Linear
- ClickUp

## Fluxo

1. Usuário conecta fontes de dados externas à plataforma.
2. Os conectores puxam e normalizam as informações.
3. Usuário solicita uma tarefa a um expert.
4. O expert analisa os dados recebidos e entrega o trabalho (análise, relatório, decisão, etc.).
